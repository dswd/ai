AI as a command

Pipe data in. Tell it what to do. Pipe results wherever you like.

The model, your data, nothing else

Work with any LLM like a normal shell command. Pass your prompt on the command line, pipe data in via stdin, and pipe the response out wherever you need it. The AI sees only what you give it — no filesystem, no network, no side effects. Every capability beyond that is an explicit choice, enabled by you and independently gated.

Optional capabilities
🌐

Web Access

Search the web via DuckDuckGo, Google, or Bing using a stealth headless browser. Fetch any URL and convert HTML to readable text. Independently gated with URL allowlists.

💻

Browser Automation

Navigate, click, extract — drive a real headless browser for JavaScript-heavy sites, login flows, and dynamic content. Requires web-fetch permission.

📁

Filesystem Access

Read-only or read-write with fine-grained permissions. Policy files, and interactive ask mode.

$>

Shell Commands

164 built-in commands (grep, sed, awk, find, tar, curl, git, …) run in-process via bashkit. Only external commands need allowlisting. Filesystem access governed by read/write policy.

🧠

Memory

Persistent long-term store for facts and project context. The model adds and deletes entries itself.

💾

Persistent Sessions

Conversations auto-saved to disk. Resume sessions to continue where you left off.

⚙️

MCP Tool Servers

Connect to external MCP servers. IDE integrations, database agents, API gateways — use any tool you want.
